# interview-prep

[![Тесты](https://github.com/maarshir/interview-prep/actions/workflows/tests.yml/badge.svg)](https://github.com/maarshir/interview-prep/actions/workflows/tests.yml)

Проводит пробное собеседование по конкретной вакансии: разбирает требования, собирает сведения о компании со ссылками, задаёт вопросы по одному с уточнениями вглубь и в конце разбирает ответы. Это навык для ИИ-агентов со стандартом [Agent Skills](https://agentskills.io): Claude Code, Codex, Cursor, Gemini CLI и других.

Статус: в работе. Сейчас готовы порядок собеседования и правила вопросов, скриптов пока нет.

## Пример

Запрос агенту:

```
Погоняй меня по этой вакансии, техническое собеседование. Резюме приложил.
<текст вакансии или ссылка на hh.ru>
```

Дальше агент коротко показывает разбор вакансии (обязательные и желательные требования, чего нет в резюме), ищет о компании и даёт ссылки, затем задаёт первый вопрос и ждёт ответа. Так выглядит обмен на одном вопросе (пример синтетический, составлен вручную):

```
Интервьюер: В вакансии бот для поддержки. В резюме у вас бот на aiogram.
            Что в нём сделали сами?
Кандидат:   Написал обработчики и подключил базу.
Интервьюер: Какую базу и почему её? Что было бы, если бы пользователей
            стало в десять раз больше?
```

В конце агент по каждому вопросу пишет, что получилось, чего не хватило и как мог бы звучать сильный ответ на материале кандидата, и называет три вещи, которые стоит подтянуть.

## Установка

Claude Code:

```
/plugin marketplace add maarshir/interview-prep
/plugin install interview-prep@interview-prep
```

Другие агенты: `npx skills add maarshir/interview-prep` или скопировать папку `skills/interview-prep` туда, где агент ищет навыки.

## Навыки

| Навык | Что делает |
|-------|------------|
| [interview-prep](skills/interview-prep/SKILL.md) | Разбор вакансии и резюме, сведения о компании из открытых источников, пробное собеседование выбранного этапа, разбор ответов |

## Как устроено

- [SKILL.md](skills/interview-prep/SKILL.md) короткий: четыре шага от вакансии до разбора. Агент читает его целиком при каждом запуске, поэтому подробности вынесены отдельно.
- [references/questions.md](skills/interview-prep/references/questions.md): как задавать вопросы о прошлом опыте по STAR, какие уточнения задавать после ответа, вопросы на компромиссы и разбор случаев, таблица банальных вопросов с заменой.
- Агенту запрещено выдавать свои вопросы за «реальные вопросы компании», а отзывы с hh.ru и dreamjob.ru он помечает как мнения со ссылкой. Иначе пробное собеседование учит отвечать на то, чего на настоящем не будет.
- Оценку «прошёл или нет» агент не ставит: по одному разговору это гадание, полезнее конкретные слабые места.

## Проверка

```
pip install -r requirements.txt pytest
python -m pytest -q
```

Тесты проверяют SKILL.md по спецификации (поля, длину описания, имя папки, размер), что все ссылки на файлы навыка существуют и что у каждого банального вопроса в таблице есть замена.
