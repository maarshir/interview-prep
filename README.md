# interview-prep

[![Тесты](https://github.com/maarshir/interview-prep/actions/workflows/tests.yml/badge.svg)](https://github.com/maarshir/interview-prep/actions/workflows/tests.yml)

Проводит пробное собеседование по конкретной вакансии: разбирает требования, собирает сведения о компании со ссылками, задаёт вопросы по одному с уточнениями вглубь и в конце разбирает ответы. Это навык для ИИ-агентов со стандартом [Agent Skills](https://agentskills.io): Claude Code, Codex, Cursor, Gemini CLI и других.

Статус: в работе. Готовы порядок собеседования, правила вопросов и скрипт разбора вакансии.

## Пример

Запрос агенту:

```
Погоняй меня по этой вакансии, техническое собеседование. Резюме приложил.
<текст вакансии или ссылка на hh.ru>
```

Дальше агент коротко показывает разбор вакансии (обязательные и желательные требования, чего нет в резюме), ищет о компании и даёт ссылки, затем задаёт первый вопрос и ждёт ответа. Так выглядит обмен на одном вопросе (пример синтетический, составлен вручную):

```
Интервьюер: В вакансии бот для поддержки. В резюме у вас бот на aiogram.
            Что в нём сделали сами?
Кандидат:   Написал обработчики и подключил базу.
Интервьюер: Какую базу и почему её? Что было бы, если бы пользователей
            стало в десять раз больше?
```

В конце агент по каждому вопросу пишет, что получилось, чего не хватило и как мог бы звучать сильный ответ на материале кандидата, и называет три вещи, которые стоит подтянуть.

## Разбор вакансии

Скрипт [parse_vacancy.py](skills/interview-prep/scripts/parse_vacancy.py) делит вакансию на разделы, чтобы агент строил вопросы по требованиям, а не по всему тексту сразу. На вход берёт текст вакансии, JSON-ответ hh.ru или ссылку hh.ru с `--fetch`, зависимостей нет.

```
python skills/interview-prep/scripts/parse_vacancy.py tests/data/vacancy_hh_synthetic.json
```

```
# Стажёр Python-разработчик (ИИ-сервисы)

- Компания: ООО «Пример Тест»
- Город: Москва
- Опыт: Нет опыта
- Зарплата: от 60 000 до 90 000 ₽, на руки

## Ключевые навыки

Python, SQL, Git

## Требования

- Python на уровне учебных проектов
- базовый SQL
- умение работать с Git.

## Будет плюсом

- опыт с API языковых моделей.

## Обязанности

- писать и тестировать обработчики на FastAPI
- готовить наборы вопросов для проверки качества ответов модели

## Условия

- гибкий график, 30 часов в неделю
- наставника & разбор кода.
```

Вакансия в примере синтетическая, компания выдумана. `--json` выводит то же в JSON, раздел, которого нет в тексте, помечается «Раздел не найден». Заголовки разделов в вакансиях пишут по-разному («Что мы ждём», «Чем предстоит заниматься», «Мы даём»), поэтому скрипт знает их частые варианты, а строку вроде «У нас дружная команда» без двоеточия заголовком не считает.

`--fetch` делает один GET к `api.hh.ru/vacancies/{id}` без ключей с заголовком HH-User-Agent (свой можно задать в `HH_USER_AGENT`). Живой запрос при разработке не проверялся: тесты подменяют ответ. Если hh.ru откажет, скрипт так и скажет и попросит сохранить текст вакансии в файл.

## Как устроено

- [SKILL.md](skills/interview-prep/SKILL.md) короткий: четыре шага от вакансии до разбора, на первом агент запускает скрипт разбора вакансии. Агент читает его целиком при каждом запуске, поэтому подробности вынесены отдельно.
- [references/questions.md](skills/interview-prep/references/questions.md): как задавать вопросы о прошлом опыте по STAR, какие уточнения задавать после ответа, вопросы на компромиссы и разбор случаев, таблица банальных вопросов с заменой.
- Агенту запрещено выдавать свои вопросы за «реальные вопросы компании», а отзывы с hh.ru и dreamjob.ru он помечает как мнения со ссылкой. Иначе пробное собеседование учит отвечать на то, чего на настоящем не будет.
- Оценку «прошёл или нет» агент не ставит: по одному разговору это гадание, полезнее конкретные слабые места.

## Проверка

```
pip install -r requirements.txt pytest
python -m pytest -q
```

Тесты проверяют SKILL.md по спецификации (поля, длину описания, имя папки, размер), что все ссылки на файлы навыка существуют, что у каждого банального вопроса в таблице есть замена, и разбор вакансии на синтетических примерах, включая `--fetch` с подменённым ответом hh.ru.
